Bragg 峰偏深 与 异质界面剂量跃变丢失：物理 + 算法分析
（参考 subSecond 与 subSecond/carbonPBS 两个解析笔形束项目）
日期：2026-06-10
================================================================================

适用范围：解释“解析笔形束(PB)计算的 Bragg 峰比 MC 深”，以及“异质界面处不能
复原剂量跃变、退化为均值平台”的物理与算法根因，并给出可加入补偿的环节。
结论性框架：两类问题相互独立——
  - 偏深 = 所有解析 PB 共有的物理系统偏差（WEPL/IDD 物理层），不是 wrapper 几何 bug。
  - 界面均值平台 = IDD(均值WEPL) ≠ 均值[IDD(WEPL)]（Jensen 不等式）+ 横向预平均。
重要约束：绝不要用几何 z-shift 去凑偏深（会与已落地的 tasks 1A.1 矛盾，方向也反）。


================================================================================
一、为什么解析笔形束的 Bragg 峰比 MC 深
================================================================================
四个独立机制叠加，主因是机制 1、机制 2。

--------------------------------------------------------------------------------
机制 1：直线 WEPL 忽略多库仑散射(MCS)的“绕路”(detour / path-length) —— 物理本质偏深
--------------------------------------------------------------------------------
真实质子(MC)：散射走弯路，实际路径 L > 投影深度 z；到投影深度 z 时已损失更多能量
            → 实际停在【更浅】的投影深度。
解析PB(WEPL)：沿直线积分 ∫ SP·ds，低估到达 z 的能量损失
            → 预测质子走得【更深】。
净效应：直线 WEPL 系统性高估投影射程 → 峰偏深。

代码落点：
  - subSecond:   bev_ray_tracing.cu:135
                 cumulSp += stepLen * tex1D(stoppingPowerTex, HU)   ← 沿直线 ray 累积 WEPL
  - carbonPBS:   weqDepth = tex3D(rayweqData, ...)，rayweqData 由 cuPrepareWEQ 沿直线投影生成

量级：detour factor 在高能(~200 MeV)约 0.1–0.3% 射程，头颈深度上约 0.5–1 mm。
注：多数水中实测/MC 标定的 IDD 表已含水的 detour；残差主要出现在异质介质中
    detour 与水不同之处。

--------------------------------------------------------------------------------
机制 2：IDD 表的 peakDepth 语义 / 射程定义（对应 tasks 6D.3）
--------------------------------------------------------------------------------
若 IDD LUT 的 peakDepth 取 CSDA range / R0（剂量→0 处）而非剂量最大深度 R100，
峰被系统性放到远端。

代码落点：
  - subSecond:   raytracedicom_wrapper.cu:5360  peakDepth = vectorInterpolate(energyData->peakDepths, energyIdx)
                 idd_sigma.cu:166               depthIdx = cumulSp * energyScaleFact
  - carbonPBS:   deviceCalDose.cu:570           iddDepthIdx = (weqDepth - iddDepth.x)/iddDepth.y

判定要点：取决于 IDD 表如何标定。
  - 若表为水中实测/MC 深度-剂量曲线 → 水中峰位正确，偏深不在这一步。
  - 若表为解析 CSDA 且 peakDepth 用 range 定义 → 偏深。
这是必须先核实的语义问题（零成本，先做）。

--------------------------------------------------------------------------------
机制 3：核反应导致初级质子耗尽
--------------------------------------------------------------------------------
质子每 cm ~1% 因核反应被移除，初级注量随深度衰减。MC 显式跟踪 → 峰更低、有效峰位
略向近端。解析 PB 若 IDD 表不含核耗尽，峰相对偏深偏高。
  - subSecond 有 nuclear/halo 路径(NUCLEAR_CORR=GAUSS_FIT)，但主要修横向 halo；
    纵向初级耗尽取决于 IDD 表是否已含。
  - carbonPBS 同理。

--------------------------------------------------------------------------------
机制 4：阻止本领 / I 值 / HU→SPR 标定不一致（方向可正可负）
--------------------------------------------------------------------------------
HU_to_SP_H&N_adj.txt 的标定若与 MC 用的 I 值不同，WEPL/HU 系统性偏移 → 射程整体平移。

偏深主因排序：机制 1（MCS 绕路，真偏深）+ 机制 2（LUT 射程语义，需核实）为大头；
              机制 3 / 4 为修正量级。


================================================================================
二、为什么异质界面不能复原剂量跃变，而退化成“均值平台”
================================================================================
本质：Jensen 不等式 + WEPL 取均值丢掉了射程方差。

--------------------------------------------------------------------------------
数学本质：IDD(E[WEPL]) ≠ E[IDD(WEPL)]
--------------------------------------------------------------------------------
一个笔形束横跨 骨/空气 界面：
  骨部分:   SP 高 → WEPL 大 → 射程短（峰浅）
  空气部分: SP 低 → WEPL 小 → 射程长（峰深）

真实剂量(MC) = 对束内 WEPL 分布求平均的剂量 = E[ IDD(WEPL) ]  → 双峰/展宽/跃变
解析PB      = 用单一均值 WEPL 查表          = IDD( E[WEPL] )  → 单一平台/平滑峰

IDD 是强非线性(尖峰)函数，故“先平均深度再查表” ≠ “查表后再平均”。界面处 WEPL
方差大时，IDD(均值) 给出落在均值深度的平滑结构，而真值是对一整段射程展布求平均
→ 被抹成平台，丢失界面跃变。即“由于 WEPL 计算变成均值平台”。

--------------------------------------------------------------------------------
算法里“取均值”发生的三个具体环节（均有代码落点）
--------------------------------------------------------------------------------
① WEQ/WEPL 横向纹理插值预平均（最直接）
   - carbonPBS: weqDepth = tex3D(rayweqData, idx, iy+deltay, ix+deltax)，LINEAR 插值
                (cudaCalDose.cpp:453, weq::LINEAR) → 界面两侧 WEPL 被双线性平均成中间值。
   - subSecond: fillBevFromWeqVolumeKernel 对 WEQ 体积做双线性采样(task 0.3) → 同样横向平均 WEPL。
   结果：界面处突变的 WEPL 被插值成连续过渡 → 峰位被抹平。

② 笔形束横向高斯叠加混合不同射程的邻居
   - subSecond: complete_superposition.cu 把每条 ray 的 IDD 按 rSigmaEff 高斯展开。
     深穿透(空气侧) ray 的峰泄漏进浅射程(骨侧)区域，反之亦然 → 界面剂量结构被卷积掉。
   - rSigmaEff (idd_sigma.cu:188) 的 σ 按水中 MCS 逐步演化
     (thetaSq = eRefSq/βp² · stepLength · rRl)，界面真实散射差异未建模 → 高斯宽度用错。

③ 单 ray 的 WEPL 是束内唯一值，无法表达“束内射程展布”
   - 一束跨界面本应分裂成“短射程+长射程”两群，但 PB 只给一个中心 WEPL → 整束堆在一个深度
     → 界面射程混合(range mixing)丢失。
   - subSecond 有 useCarbonSubspotConvolution(子斑分裂)，但 raytracedicom_wrapper.cu:4341
     硬编码为 false → 恰好关掉了能部分恢复束内展布的路径（对应 tasks 6A.5）。

三、能在哪些环节加补偿
================================================================================

--------------------------------------------------------------------------------
对“偏深 vs MC”
--------------------------------------------------------------------------------
C1  MCS 绕路修正
    环节：WEPL 累积处(cumulSp) 乘深度/能量相关 detour 因子(<1)，或等价缩有效射程。
    依据：真实路径 L>z，直线积分高估射程。
    风险：因子需标定；最干净是直接用含 detour 的水中 IDD。

C2  核实 LUT peakDepth 语义（对应 6D.3，零成本，先做）
    环节：IDD 表加载/索引。
    依据：range vs 剂量最大深度。

C3  用含核耗尽+straggling 的 MC/实测水中 IDD
    环节：IDD 表本身。
    依据：让水中峰位/峰形先对。
    风险：依赖表来源。

C4  距离歧离(range straggling)卷积
    环节：若 IDD 为单能 CSDA，对其卷一个 range-straggling 高斯。
    依据：展宽+压低+略前移峰。
    注：多数实测表已含。

判断：先做 C2（核实表语义，零成本），再评估 C1（detour）。
      若 carbonPBS≈TPS 都比 MC 深（已观察到），说明这是解析引擎相对 MC 的系统性量，
      不是 wrapper bug（tasks 6D.1）→ 补偿应加在所有 PB 共享的 WEPL/IDD 物理层，
      而非 wrapper 几何层。绝不要用几何 z-shift 去凑（会与 tasks 1A.1 矛盾且方向反）。

--------------------------------------------------------------------------------
对“界面跃变 / 均值平台”
--------------------------------------------------------------------------------
D1  子斑/射程分裂（物理上最对路）
    环节：打开并修正 useCarbonSubspotConvolution，每斑用多个 WEPL 采样。
    依据：恢复束内射程展布，把 IDD(E[WEPL]) 升级成 E[IDD(WEPL)]。
    代价：中（对应 6A.5 决策）。

D2  细化 WEQ/ray 网格
    环节：WEPL 生成分辨率。
    依据：减少横向预平均。
    代价：高（性能，正是 subSecond 的痛点）。

D3  WEQ 纹理界面处改最近邻 / 不预平均
    环节：tex3D LINEAR → 界面感知采样。
    依据：不把突变 WEPL 插成均值。
    代价：中，可能引入阶梯噪声。

D4  异质散射修正(Kanematsu 等)
    环节：rSigmaEff 的 σ 演化按局部介质散射本领修正，而非纯水。
    依据：界面处高斯宽度用对。
    代价：中高。

判断：界面问题根子是“单 WEPL 均值”——D1（子斑/射程分裂）最对路。
      D2/D3 缓解横向预平均，D4 修横向散射宽度。
      纯 PB 无法完全复原 MC 的界面跃变——这是解析模型的理论上限，能逼近，不能等价。


================================================================================
四、一句话总括
================================================================================
偏深 主要来自直线 WEPL 忽略 MCS 绕路(机制1) + LUT 射程语义(机制2)，是所有解析 PB
共有的物理系统偏差，补偿应加在 WEPL/IDD 物理层(C1/C2)，不能用几何 z-shift。
界面均值平台 来自 IDD(均值WEPL) ≠ 均值[IDD(WEPL)] (Jensen) + WEQ 横向插值预平均 +
横向高斯混合，补偿在子斑/射程分裂(D1)最对路，但 PB 有理论上限。
